# 源码注释的纪律表（R20）
#
# 单一来源：`ios/tests/CommentDisciplineTests.swift` 读它，判据不内联模式 ——
# 模式词表本身含中文（「此前」「原为」），写进 `.swift` 会被这条判据自己扫到。
#
# 格式（分号分隔，`#` 开头为注释）：
#   规则      <id>;<正则>;<一句话说明>
#   expect-hit  <id>;<一句应当被拦的话>
#   expect-pass <id>;<一句应当被放过的话>
#
# 两条纪律：
#   1. **每条规则至少一条 expect-hit**，缺了判据直接失败。零命中型判据最危险的失效
#      是正则退化成永不命中 —— 那时全仓变绿而没人知道。
#   2. **只收能说出形状的**。语义重复（同一判断换句话写）识别不了，那部分靠人读，
#      不假装有判据。
#
# 扫描面：`ios/Sources` 与 `ios/tests` 下的 `.swift`，逐行匹配**含注释标记的行**
# （`//`、`/*`、行首 `*`）。不剥字符串 —— 剥字符串要写词法器，写错时是漏报；
# 按行粗扫写错只会多报。行内豁免：`comment-ok: <理由>`，理由为空即失败。

# ── 组一：指向开发工作区 ────────────────────────────────────────────────
# 这些锚点全在 `dev/`，而它不进 git：仓库读者手里没有那份索引，编号等于空指针。
rule;workspace-path;dev/;开发工作区的路径不随仓库发布
rule;workspace-phase;\bR\d{1,2}\b;期号只在 dev/ 里有索引
rule;workspace-decision;决定\s*[A-Z]?\d;决定编号同上
rule;workspace-section;§;节号会随文档增删静默指错
rule;workspace-clause;spec\s*\d;需求条款号同上
rule;workspace-chain;链路\s*[A-C]\b;链路编号同上
rule;workspace-amendment;修正\s*\d+;实施期修正编号同上
rule;workspace-criterion;\b[QNG]\d{1,2}\b;判据编号同上
rule;workspace-milestone;\bM\d{1,2}\b;里程碑编号同上
rule;workspace-register;ISSUES\s*[A-F]?\d*;登记簿条目号同上
rule;workspace-phase-word;期\s*[1-9](?!\d);期次说法同上

# ── 组二：按位置引上游 ──────────────────────────────────────────────────
# 上游按 tag 跟、是 alpha：连 patch 级预发布内都会改形状，行号必漂。
# 我们依赖的是形状，形状能用符号名与结论说清。
rule;upstream-line;[\w\-/.]+\.(ts|tsx|js|mjs|swift):\d+;上游 alpha 的行号会漂

# ── 组三：变更史与一次性现场 ────────────────────────────────────────────
# 前者描述一个已不存在的对象，实现换掉后它不会失效、只会继续误导；
# 后者是举证，读完不增加判断力 —— 它推导出的数值与顺序才要留。
rule;history;此前|原为|原先是|旧版|上一版|搬家|搬走|搬进|搬回|重构前|曾经|已经不一致过|更早的写法;注释写现状，不写演进
rule;scene-date;真机\s*20\d\d;一次性观测的日期不是判据
rule;scene-evidence;真机抓到|真机复验|真机产物|第三次真机|收口审查|实施期修正;举证不是判据

# ── 组五：注释里的元信息 ────────────────────────────────────────────────
# 这两类不回答「这段为什么这样写」，只回答「它在哪、当初怎么决定的」。
# 跑法在全仓是一条命令，不必每个文件写一遍；分层理由若真要保留，写「变化原因是什么」，
# 不写「为什么没放进另一个目录」—— 后者是审查时的论证，读者要的是结论。
rule;meta-test-run;xcodebuild test|only-testing:;测试怎么跑是全仓一条命令，不写进每个文件
rule;meta-defence;为什么住|分家的理由|住在[^。]*的代价;注释写变化原因，不写「为什么没放进另一个目录」

# ── 组四：同一判据只展开一处 ────────────────────────────────────────────
# 每组的短语加起来在 `Sources/` 里只允许出现一次。只认原句：换个说法重写抓不到，
# 那部分靠评审（已知盲区，不假装覆盖）。
single;身份轴与连接阶段;两轴正交
single;帧与名单的先后;名单只是连接那一刻的快照
single;洞与位置否定的分档;内容是旧的，但不是错的
single;连接态的读取面;连接域唯一出处
single;连接态的读取面;视图读连接态的唯一出处
