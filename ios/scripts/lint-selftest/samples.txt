# 规则的核查样本
#
# 用途：`scripts/lint-selftest.sh` 读它，逐条断言「这条规则还认得出它的正例、也没误伤反例」。
# 规则被改坏（正则退化成永不命中）时这里先红，不必等仓库真的回潮。
#
# 格式：`#` 开头为注释；其余每行 `expect-hit;<规则 id>;<一句应当被拦的话>` 或
# `expect-pass;<规则 id>;<一句应当被放过的话>`。
#
# 两条纪律：
#   1. **每条规则至少一条 expect-hit 与一条 expect-pass**。只有正例的规则证明不了它不误伤。
#   2. 样本 id 必须在 `ios/.swiftlint.yml` 里有同名规则 —— id 改了而样本没改，脚本判红。
